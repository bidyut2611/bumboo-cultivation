# Bamboo Cultivation Platform

A web application platform dedicated to bamboo cultivation, connecting supply chain, tracking species, and requirements.

## Project Structure
- `index.html`: Main entry point
- `css/`: Stylesheets
- `js/`: Application logic (`app.js`, `search.js`, `data.js`, `utils.js`)

## Running Locally
You can run this project by serving it with a local web server on port 3000.
